Accessible Profile Website

This project was completed as part of my university coursework. It was designed from scratch using only native HTML, CSS, and JavaScript. The focus was on creating an accessible, standards-compliant website with conformance to WCAG 2.1 AA.

Features:

  • Alt text and ARIA labels for assistive technology
  • High-contrast color schemes and keyboard navigation
  • WAVE-tested with zero critical errors
  • Heuristic evaluation documented in detail

Technologies: HTML5, CSS3, GitHub, JavaScript

AI Inventory Tracker (Concept)

This project proposes a predictive AI model for warehouse stock management. It is intended to improve planning, reduce downtime, and ensure better demand fulfillment through intelligent forecasting techniques.

Planned System Components:

  • ETL pipeline for historical inventory data
  • Regression models (Linear, Random Forest, ARIMA)
  • Interactive reporting dashboard (Plotly / Matplotlib)
  • Potential API integrations with ERP systems

Technologies: Python, Pandas, Scikit-learn, Flask (planned), SQL
