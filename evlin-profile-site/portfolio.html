Accessible Profile Website

This project was developed for the Accessibility and Usability module. The goal was to build a multi-page portfolio using only HTML, CSS, and JavaScript — without any frameworks or libraries. Key highlights include:

  • Strict adherence to semantic HTML5 elements
  • WAVE-based conformance test to WCAG 2.1 Level AA
  • Heuristic evaluation based on Nielsen's principles

This project reflects not only my coding skills but also my attention to ethical and inclusive design practices. It was pushed and version-controlled through GitHub and hosted via GitHub Pages.

AI Inventory Tracker (Concept)

This is a conceptual project designed to demonstrate how AI can be used to forecast inventory demand in a warehouse environment. The system was planned to integrate time-series analysis with real-world warehouse constraints such as lead times and restocking delays.

The proposed features include:

  • Historical trend analysis using Python (Pandas, NumPy)
  • Machine learning algorithms like ARIMA and Decision Trees
  • Custom dashboards for warehouse managers

Though the project is in the design phase, it builds on my work experience and technical background, aiming for real-world industrial applications in smart logistics and supply chain automation.
