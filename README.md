# Evlin Varghese – Accessible Profile Site

This is a personal portfolio website created by **Evlin Varghese** as part of the Accessibility and Usability (5COM2002) module at the University of Hertfordshire. The project showcases semantic HTML, accessible design, and standards-compliant front-end development.

---

## 🔍 About This Project

The website is designed using only **vanilla HTML, CSS, and JavaScript** — without any templates or libraries. The project is focused on accessibility (WCAG 2.1 AA), heuristic usability evaluation, and semantic structure.

## ♿ Accessibility Focus

- ✅ WCAG 2.1 Level AA Conformance  
- ✅ Tested with WAVE Evaluation Tool  
- ✅ Semantic HTML, proper alt text, color contrast  
- ✅ Focus visibility and keyboard navigation

## 📊 Usability Evaluation

The site was evaluated using **Nielsen’s 10 Usability Heuristics**.  
A full heuristic evaluation report is provided as a `.docx` file for submission.
